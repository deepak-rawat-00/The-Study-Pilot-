# The Study Pilot 🚀

> Free Study Planner & Progress Tracker for Students and Lifelong Learners.

Plan study sessions, track study hours, build consistent study habits, and count down to exams with **The Study Pilot**.

## Features

- ⏱️ **Focus Study Timer**: Track deep work sessions with customizable Pomodoro or stopwatch modes.
- 🔥 **Streak & Consistency Tracker**: Build momentum and maintain study streaks with interactive heatmaps.
- ⏳ **Exam Countdown**: Keep key exam dates and preparation milestones front-and-center.
- 📊 **Analytics & Insights**: Visualize subject-by-subject study distribution and weekly progress.
- 🌓 **Dark & Light Mode**: Clean, distraction-free interface designed for extended study sessions.
- 💾 **Local-First & Privacy-Focused**: Your study data stays on your device.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS, Lucide Icons
- **Build Tool**: Vite
- **Testing**: Vitest

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/deepak-rawat-00/The-Study-Pilot-.git
   cd The-Study-Pilot-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
